One line of weather for a city that does not exist, written for a bored commuter at a rainy bus stop — made for the [make.fun](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e) bounty "Charm the Commuter: Forecast a City That Isn't".

## Entry

> Wobbleford: light drizzle until 8am, then sunshine. Buses on time for once — bring an umbrella anyway, the sky changes its mind.

(128 characters, invented city Wobbleford.)

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt`. Deterministic, standard library only.
